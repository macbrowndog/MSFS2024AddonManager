# Security policy

## Reporting a vulnerability

Please do not publish vulnerabilities involving filesystem operations, privilege elevation, or installer execution in a public issue.

Use GitHub's private vulnerability reporting feature when it is enabled for this repository. Otherwise, contact the repository owner privately and include:

- the affected version;
- the relevant source and destination paths with personal information removed;
- reproduction steps;
- the expected and actual result; and
- whether any real addon data was moved, overwritten, or deleted.

## Supported versions

Security fixes are provided for the latest released version. Users should upgrade before reporting a problem that has already been corrected in a newer release.
